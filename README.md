## 📖 About

This is a single-page portfolio site designed to give a quick, clear overview of who I am professionally — my background, technical skills, and the projects I've built. Built from scratch using vanilla HTML/CSS/JS, without any frameworks.

## ✨ Features

- Responsive design — works across desktop and mobile
- Sections for About, Skills, Experience, and Projects
- Clean, single-page layout for easy navigation
- Built with vanilla JavaScript (no frameworks/libraries)

- **HTML5** — structure and content
- **CSS3** — styling and responsive layout
- **JavaScript** — interactivity

1. Clone the repository:
```bash

```
2. Open `index.html` directly in your browser, or serve it locally:
```bash
   cd portfolio
   npx serve .
```
